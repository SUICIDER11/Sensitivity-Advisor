10 cm calibration instructions

Mark 10 cm on your mousepad with a ruler. Click Calibrate, move the mouse horizontally in one direction exactly 10 cm without lifting it, then press Space. Repeat. Two measurements must agree within 10%. You can also press Esc and click Finish measurement.

Use your actual mouse-driver DPI. Disable system / driver acceleration; this trainer applies its own optional curve after calibration. Unadjusted capture can be selected, but availability varies. Visible cursor mode uses screen pixels and OS pointer settings. At high DPI, 10 cm may exceed the visible area: use captured mode for calibration, or lower OS pointer speed before calibrating and keep it fixed. Never reuse calibration between input modes. Calibration only approximately compensates adjusted input; it cannot remove speed-dependent acceleration. Recalibrate after any DPI, browser or input-mode change.

How the recommendation works

Three physical sensitivities, three tasks each: nine rounds. Each task starts from the same seeded target sequence; candidate order rotates between tasks. Flick and precision scores use successful clicks/second; tracking uses time on target. Each score is normalized against the best candidate in that task, then weighted by your preference. The recommendation is always a sensitivity you actually tested.

With acceleration off, matching cm/360° matches horizontal hipfire turning distance. With acceleration on, the reported distance is the low-speed base distance; faster movement uses a higher gain. Different FOVs, aspect ratios, recoil and ADS systems can still feel different. There is no single guaranteed best sensitivity for every FPS. Small score differences need repeat sessions. eDPI is game-specific and is not averaged across games.

Conversion assumptions and sources

Optional acceleration uses gain = min(cap, 1 + rate × max(0, speed − start speed)). Speed is estimated from pre-curve mouse movement in cm/s with 25 ms exponential smoothing. The same fixed curve is used for all nine rounds; the test chooses a base sensitivity, not an optimized acceleration curve. Event timing and adjusted browser input can affect the estimate. This is an original trainer model, not an emulation of Windows Enhance Pointer Precision or a driver preset.

HTML cannot enable acceleration in another game or change your mouse driver. The game values below transfer only the base sensitivity. To reproduce accelerated behavior in a game you need a separately configured compatible input method and matching curve; parameter names alone do not establish a match. Otherwise turn acceleration off here and retest. The any-game converter assumes constant sensitivity: disable acceleration when measuring, or measure at a defined constant speed and treat the result as speed-specific.

cm/360° = 914.4 / (DPI × sensitivity × yaw). Presets use conventional default yaw values: CS2 / Apex 0.022, VALORANT 0.07, and CoD MW / Warzone / Overwatch 2 0.0066 degrees per count at sensitivity 1. These are reference presets, not live readings of your installed game. CoD titles and settings can differ; use physical measurement for unsupported versions. CS2 assumes default m_yaw. The custom converter uses new sensitivity = known sensitivity × measured cm / desired cm.

Rounded outputs show the resulting physical distance and rounding error. The app does not silently clamp game values. Check that your particular game accepts the number; use the custom converter for any unsupported game or changed scale. The tests are original Aimlabs-style exercises, not official embedded Aimlabs.
